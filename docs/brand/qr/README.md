# Adro QR code

All versions open **https://adroapp.com/get** (checked: they scan at small sizes too, the dark and blue ones included).

| File | Use |
|---|---|
| adro-qr.svg / .png | White, with "Get adro" under it (print, posters, the box) |
| adro-qr-plain.svg / .png | White, no text |
| adro-qr-dark.svg / .png | On black (the black box, dark slides) |
| adro-qr-blue.svg / .png | On Adro blue |
| adro-qr-round*.svg / .png | Round version: the code inside a blue circle, round eyes, light dots filling the rest (white, white with "Get adro", dark, blue) |

The SVG files are for print (sharp at any size). Keep the code at least 2 cm wide, with a small quiet border around it.

## Where it goes

adroapp.com/get (public/site/get.html) is a small page with two buttons, **App Store** and **Google Play**, in English or Arabic (from the phone's language). The button for your own phone comes first, in blue.
- **Now:** both say "Soon".
- **When a store is live:** put its link at the top of public/site/get.html (`IOS = '…'`, `ANDROID = '…'`). The App Store link is `https://apps.apple.com/app/id6826500429`.

The printed code never has to change: only the page behind it does.
