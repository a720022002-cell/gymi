منطق جدول التمارين في Adro

كيف يبني التطبيق الخطة، والفرق بين يوم A ويوم B، وقواعد كل يوم. حسب كود التطبيق كما هو الحين.

1. كيف يختار التطبيق نوع الجدول

حسب عدد أيام التمرين، والمستوى، والهدف، والعمر:

الأيامالجدولليش
2Full body A / Bالطريقة الوحيدة اللي تمرّن كل عضلة مرتين بالأسبوع
3Upper / Lower / Full bodyالمبتدئ، أو 50 سنة وفوق، أو هدفه تنشيف: Full body × 3
4Upper A / Lower A / Upper B / Lower Bكل عضلة مرتين، وبينهم يوم راحة
5Upper / Lower / Push / Pull / Legsالمبتدئ: Upper/Lower × 2 + Full body
6Push A / Pull A / Legs A / Push B / Pull B / Legs Bللمتوسط والمتقدم. المبتدئ يطلع له Upper/Lower × 3
يعني جدول PPL ما يطلع إلا لمن يتمرن 6 أيام ومستواه متوسط أو متقدم.

توزيع الأيام في الأسبوع (6 أيام)

Push Aالأحد
Pull Aالاثنين
Legs Aالثلاثاء
Push Bالأربعاء
Pull Bالخميس
Legs Bالجمعة
Restالسبت

بين كل يوم وتكراره 3 أيام، فالعضلة ترتاح قبل ما تشتغل مرة ثانية.

2. الفرق بين يوم A ويوم B

يوم A: قوةيوم B: حجم
الفكرةتمارين مركّبة ثقيلة (بار وفري ويت)حجم أكثر وتنويع: دمبل، كيبل، أجهزة، زوايا مختلفة، تمارين بيد أو رجل وحدة
التكرارأقل، وأوزان أثقلأكثر، وأوزان متوسطة
القاعدةممنوع يتكرر نفس الشي بين A و B. كل يوم لازم يكون مختلف.

أمثلة

اليومA (قوة)B (حجم)
PushBarbell bench → Barbell incline → Fly → Barbell shoulder press → Lateral raise → TricepsDumbbell bench → Incline machine → Cable fly → Dumbbell shoulder press → Cable lateral → Overhead triceps
PullBarbell row → Heavy pulldown → Cable row → Face pull → Barbell curlSingle-arm row → Machine pulldown → Chest-supported row → Rear delt fly → Dumbbell / hammer curl
LegsBack squat → Romanian deadlift → Leg press → Leg curl → CalvesLeg press / hack squat → Lunges / single-leg → Leg extension → Leg curl → Calves → Core

3. قواعد كل يوم

البندالقاعدة
عدد التمارين والوقت4 إلى 7 تمارين، 45 إلى 70 دقيقة
الترتيبالعضلة كاملة قبل اللي بعدها: المركّب أول، وبعده العزل. العضلات الكبيرة (أرجل، صدر، ظهر) أول، بعدها الكتف، بعدها الذراع، والبطن آخر شي.
مثال: صدر مستوي ← صدر علوي ← تجميع ← كتف ← ترايسبس
التكراراتالمركّب 6–10 (للقوة 4–6) · العزل 10–15 · السمانة والبطن 12–20
المجموعات2 إلى 5 لكل تمرين
الحجم الأسبوعيكل عضلة 10–16 مجموعة صعبة بالأسبوع (المبتدئ 8–12)، تتوزع بين يوم A ويوم B
التوازنالدفع والسحب متوازنين، وكل عضلة رئيسية مرتين بالأسبوع على الأقل

حسب المستوى

المستوىالقاعدة
مبتدئأجهزة ودمبل، 4–5 تمارين، غالباً 3 × 10–12، وعضلتين بالكثير لكل منطقة. وما يطلع له PPL أصلاً
متوسط5–6 تمارين، 3–4 مجموعات
متقدم6–7 تمارين، المركّب الحر أول بـ 4–5 مجموعات، وأول تمرينين فيهم مجموعة زيادة

حسب الهدف

الهدفالقاعدة
تنشيفيحافظ على التمارين الثقيلة عشان العضلة ما تروح، والحجم أقل شوي
تضخيمأكبر حجم
محافظةبين الاثنين

الإصابات

أي تمرين يضغط على الإصابة اللي اختارها المستخدم (كتف، أسفل ظهر، ركبة، كوع، رسغ، رقبة، ورك) ينحذف تلقائياً، ويتبدل بتمرين آمن لنفس العضلة. والتطبيق يتأكد بنفسه، حتى لو الذكاء الاصطناعي غلط.

4. ضمانات التطبيق

  • التمارين من قائمة التطبيق بس، وكل تمرين مرة وحدة في اليوم.
  • بعد ما يرجع التمرين من الذكاء الاصطناعي، التطبيق يعيد ترتيبه بنفس قاعدة الترتيب فوق.
  • إذا فشل الذكاء الاصطناعي، يستخدم التطبيق الجدول الجاهز بدال الخطة الناقصة.
  • وقت التمرين يتحسب من عدد المجموعات.
⚠️ ملاحظة مهمة: الفرق بين A و B ينطبق بس لما يسوي الخطة الذكاء الاصطناعي. إذا المستخدم اختار الجدول الجاهز (Push / Pull / Legs × 2)، أو فشل الذكاء الاصطناعي ورجع للجاهز، فيوم Push الأول والثاني نفس التمارين، لأن الجاهز فيه نسخة وحدة من كل يوم.
الحل المقترح: نسخة B جاهزة لكل يوم (Push B / Pull B / Legs B) بفكرة "A قوة، B حجم".
